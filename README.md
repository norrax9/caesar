# Шифр Цезаря

Программа шифрует текст шифром Цезаря. Работает с английскими и русскими буквами, регистр сохраняется. Цифры, пробелы и знаки препинания не меняются.

## Запуск


python caesar.py


Программа попросит ввести текст и сдвиг.

## Пример


Введите текст: Hello, Мир!
Введите сдвиг: 3
Khoor, Плу!
